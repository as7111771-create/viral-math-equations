# Viral Math Equations

> **100 auto-generated math problems — from dead simple to olympiad-hard — each with an answer and a step-by-step explanation. Built for viral social media content.**

## What's Inside

- **10 difficulty levels x 10 problems each = 100 total**
- Every problem has: the question, the answer, a worked explanation, and a "viral hook" (a punchy caption for social media)
- Topics span: Arithmetic, Pre-Algebra, Algebra, Geometry, Trigonometry, Logarithms, Calculus, Probability, Olympiad

## How to Use for Viral Content

1. **Pick a problem** from any level file in `problems/`
2. **Post the question** as your hook (image, reel, or story)
3. **Reveal the answer + explanation** in the next slide, comment, or story
4. **Use the "viral hook"** text as your caption to drive engagement
5. **Mix levels** — easy problems get wide reach, hard ones get saves and shares

### Content Ideas
- *"Can you solve this in 10 seconds?"* — Level 1-3 problems
- *"99% of people get this wrong"* — Level 4-6 problems
- *"Only geniuses can solve this"* — Level 7-10 problems
- Series: "Math Challenge Day 1-100"
