# Contributing to Viral Math Equations

First off, thanks for taking the time to contribute! 🎉

## Ways to Contribute

- Report bugs or suggest features by opening an issue
- Improve existing math problems or add new ones
- Enhance the problem generator script
- Improve documentation
- Share the project with others

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/viral-math-equations.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Push: `git push origin feature/your-feature-name`
6. Open a Pull Request

## Guidelines

- Keep problem descriptions clear and concise
- Include step-by-step explanations for solutions
- Test any code changes before submitting
- Follow the existing file structure
- Write meaningful commit messages

## Problem Format

Each problem should include:
- A clear problem statement
- The correct answer
- A step-by-step explanation
- Difficulty level (simple, medium, hard, hardest)

## Code Style

- Follow PEP 8 for Python code
- Use meaningful variable names
- Add comments where necessary

## Questions?

Feel free to open an issue with the `question` label!
